# Electron开发HarmonyOS应用知识地图

如果您在其他平台未使用过 Electron 框架，不建议您直接使用该框架。您可以从自身软件跨平台演进整体规划上对跨平台框架进行选择。
 
  Electron 是一个使用 JavaScript、HTML 和 CSS 构建桌面应用程序的框架。通过将 Chromium 和 Node.js 嵌入到它的二进制文件中，Electron 允许您维护一个 JavaScript 代码库，并创建可以在 Windows、macOS、Linux 和 HarmonyOS 上运行的跨平台应用程序。
